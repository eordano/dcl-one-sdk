# experiments

Proven work kept because the evidence behind it cost more to produce than the
code, and re-deriving it would mean repeating the campaign. Most of it is
deliberately **not** shipped; one entry now is, and says so.

## `protobufjs-minimal-replacement/` — SHIPPED

A dependency-free drop-in for the `protobufjs/minimal` runtime that `@dcl/ecs`
uses for the CRDT wire format — 45 KB, 1,352 lines, replicating `Reader`,
`Writer`, `util.Long` and `configure()`.

**It ships.** `add_pbmin()` in `scripts/build-base-blob.py` writes `index.js`
and `LICENSE` from this directory into the blob as `node_modules/protobufjs`,
and no upstream protobufjs file is shipped at all. This directory is therefore
*source*, not an experiment — treat an edit to `index.js` as an edit to shipped
code, and run the suite below before and after.

**Why it was shelved, and what changed.** The size argument was that it removes
`protobufjs` plus its `@protobufjs/*` micro-packages at the cost of ~50 KB of
our own, for a net saving under 1% of the blob — which did not justify
permanently owning a hand-written codec on the critical path of the scene
protocol. Measured on the actual swap it is **-34 files, -51,649 B unpacked,
-25,873 B zipped** (447 -> 413 files). So the size argument has not improved,
and it is not why this shipped.

What changed is the risk. One direction down, one direction up — and the second
is a deliberate trade, not an oversight:

* `protobufjs/minimal` gained two consumers — `@dcl/rpc` (the framing every byte
  of the data-layer socket passes through) and the vendored 22-method data-layer
  descriptor — and **neither had ever been round-tripped against this
  implementation**; the corpus phase only ever loaded `@dcl/ecs/dist-cjs`. They
  now are, by `tests/rpc-diff.js`: 41 namespaces, four environments, zero
  divergences, and two of the 13 mutation-test bugs are caught by that phase and
  *not* by the `@dcl/ecs` corpus phase. What used to be an untested surface is
  the best-tested one.
* **The scene runtime is now a consumer, and that is a risk increase.**
  `swap_pbmin_into_tree()` redirects the install tree's `minimal.js` before
  `build_chunks()` resolves it, so `prebuilt/core.js` bundles this code and
  every scene runs it inside QuickJS. Two things follow, and both are worse than
  the node-only arrangement they replace: a defect here is visible in every
  deployed scene rather than in one dev-machine process, and the suite runs
  under V8, so QuickJS remains an untested axis — a real one, since this code
  reaches for `Buffer`, `Uint8Array` fast paths and `Math.fround`.

  It was taken anyway, on purpose. The arrangement it replaces shipped **two**
  protobuf codecs in one extracted scene — this one in `node_modules`, upstream's
  minified inside the chunk — and the runtime ran the copy nobody in this repo
  owned or tested. Splitting the wire format across two implementations to
  reduce exposure to one of them is not a real safety property; it just moves
  which bugs are findable. One codec, tested to the bar below, beats two.

  The claim that used to sit here — "the scene runtime is not a consumer, so the
  untested axis is gone" — was true when written and is now false. Do not
  restore it as an argument for shipping.

**The obligation stands.** Two upstream inconsistencies are reproduced on
purpose and must not be "fixed": `BufferWriter.string` and `Writer.string`
encode lone surrogates differently, and `BufferReader.string` clamps a truncated
length with `Math.min` where `Reader.string` throws. The suite pairs like for
like, so "cleaning up" either one turns it red. That is the point.

**Running it.** `bash tests/setup.sh` first — it rebuilds the scaffold the
phases need (the reference protobufjs, both corpora, the symlinked
`node_modules`) entirely out of the committed blob plus one scene's
`@dcl/ecs/dist`, and everything it writes is gitignored. Then
`bash tests/run-all.sh [seed]`.

`setup.sh` refuses to run if the blob's `node_modules/protobufjs` is no longer
upstream's — which, since the swap, it is not. Point it at an install tree that
still has upstream 7.2.4, or install `protobufjs@7.2.4` into `ref/node_modules`
by hand. A differential suite whose reference is the implementation under test
would report a perfect score and mean nothing.

**Evidence**, per seed, with upstream 7.2.4 loaded side by side as the reference
and every corpus module bound to exactly one implementation (asserted each run
by `verify-isolation.js`, for both corpora):

* Round-tripped **all 336 message namespaces** (142 unique types) generated by
  `@dcl/ecs`, 300 instances each = 100,800 per environment, across four
  environments (Buffer/no-Buffer x Long/no-Long). Asserts byte-identical
  encoding in both directions, deep-equal decodes, and throw-parity including
  error message.
* The ESM `dist/` build of the same corpus: 244 namespaces x 100 = 24,400.
* **All 41 namespaces of the two catalogues that are not `@dcl/ecs`** —
  `@dcl/rpc/dist/protocol/index.js` (11) and `@dcl/inspector/data-layer.gen.js`
  (30) — 2,000 instances each across the same four environments = 82,000 per
  environment, plus an assertion that all 22 descriptor methods' request and
  response types were among the namespaces covered.
* **800,000 fuzz operations** against random, truncated and corrupted input,
  where both implementations must agree on *which* inputs throw. 26,211 of the
  message decodes were inputs the reference rejected.
* **Zero divergences** in the library, over 6 seeds (`0xC0FFEE`, `0x1`,
  `0xDEADBEEF`, `0x5EED`, `0xBADF00D`, `0x2A`). Three bugs have been found in the
  harness itself, every one of which would have faked a pass: node's
  `Module._load` relative-resolve cache silently handing one pass the other
  pass's implementation; an ESM `?query` import instantiating a second copy of
  protobufjs's internal require cycle; and `deepEq` comparing ts-proto's
  `useMapType=true` map fields with `Object.keys`, which reports every `Map` as
  empty and so found every map field equal (the data-layer descriptor has one,
  `ImportAssetRequest.content`).
* **Mutation tested**: 13 deliberate wire-format bugs injected, 13 caught, most
  by 2-4 independent phases.
